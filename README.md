# ورشة الرحى لصيانة الأجهزة المنزلية — نسخة عرض (Vue 3 + Vite)

موقع عرض تجريبي ثنائي اللغة (عربي/إنجليزي) لورشة الرحى — شارع ابن سينا، حي المصيف، الرياض.

## التشغيل
```bash
npm install
npm run dev
npm run build   # dist/
```
Vercel: Build `npm run build` — Output `dist`.

## الهوية والفكرة
- ألوان لوحة المحل: كحلي/أسود + أزرق دائرة الشعار + أبيض، مع لمسة كهرماني (لون «تحذير/ورشة»).
- طابع «ورشة فنية»: شبكة مخططات هندسية، إطار فحص للصورة مع خط مسح، أكواد قطع (BL / FR / IR…) بخط Mono.
- **«شخّص جهازك»**: يختار العميل الجهاز ← العطل (الأعطال تتغير حسب الجهاز) ← التفاصيل، وتتكون «بطاقة صيانة» حية برقم، تُرسل كرسالة واتساب.
- **باحث قطع الغيار**: يكتب اسم القطعة والموديل ← واتساب «اسأل عن التوفر».
- صور حقيقية من خرائط Google: الواجهة ليلاً، داخل المحل، رفوف وجدار قطع الغيار.

## نقاط تُؤكَّد مع العميل
- لا أسعار ولا ضمان ولا مدة إصلاح في الموقع عمداً.
- أسماء أقسام قطع الغيار عامة ومبنية على الصور — تُعدَّل حسب المتوفر فعلاً.
- إحدى المراجعات تشتكي من التأخر في الفتح بعد الصلاة — أضفنا تنبيه «المحل يُغلق وقت الصلاة».
- موقعهم المسجل al-rraha.com لا يعمل (النطاق ميت) — زاوية بيع مباشرة.
